# JavaLab

Java fundamentals and object-oriented programming exercises.

## Requirements

- JDK 17 or newer
- Visual Studio Code with the Java extensions, or a terminal with `javac` and `java` on `PATH`

## Source files

Java source files are in `src/`. Compile and run an example from the project folder:

```sh
javac -d bin src/Hello.java
java -cp bin Hello
```

Use the same pattern with `Arithmetic.java` or `Variables.java`. Generated `.class` files belong in `bin/` and should not be committed.
